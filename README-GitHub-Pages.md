# UniSafe GitHub Pages source

The deployable site is `index.html`. It contains the UniSafe incident-reporting prototype and the full project report view.

Keep these downloadable documents in the repository root so the links in the site work:
- `UniSafe-Project-Report.pdf`
- `UniSafe-Final-Submission.pdf`
- `UniSafe-Presentation.pptx`

GitHub Pages should be configured to publish the `main` branch from the repository root.
